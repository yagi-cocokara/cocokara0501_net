# YouTube ショート 予約投稿ツール（無料）

Google ドライブに置いた動画を、Google スプレッドシートの一覧から **YouTube に一括アップロードして予約公開** するツールです。
Google Apps Script（無料）と YouTube Data API（無料）だけで動きます。

```
Google ドライブ（動画）
        ↓
スプレッドシート「投稿予定」（タイトル・説明・公開日）
        ↓  メニュー「④ 予約アップロードを実行」
YouTube（非公開でアップロード → 指定日時に自動で公開）
```

## 毎月の作業（設定が終わったあと）

1. 今月分の動画を Google ドライブの「動画フォルダ」に入れる
2. メニュー **YouTube予約投稿 → ② ドライブから動画を取り込む**
3. タイトル・説明・タグを入力する。**YouTube 向けでない動画は「投稿する」のチェックを外す**
4. メニュー **③ 公開日を自動で割り振る**（土曜を飛ばして、明日以降の空いている日に1本ずつ割り振ります）
   - 日付を手で入れた行はそのまま使われます
5. メニュー **④ 予約アップロードを実行**
   - 「ステータス」列に「予約済み（11/3 18:00 公開）」と出れば完了です
   - 本数が多くて6分の実行制限を超えそうなときは、途中で止まり、1分後に自動で続きを再開します
   - エラーが出た行は内容を直して ④ をもう一度実行すれば、その行だけ再挑戦します

YouTube は、縦長で3分以内の動画を自動でショートとして扱います（10〜70秒の動画ならそのまま対応できます）。

---

## 最初に1回だけやる設定

所要時間は30〜60分くらいです。**手順 C の審査が通るまでは、アップロードした動画が「非公開」のまま固定され、予約日時になっても公開されません。** 審査には数週間かかることがあるので、早めに申請してください。

### A. Google Cloud プロジェクトを作る（無料）

1. <https://console.cloud.google.com/> を開く（YouTube チャンネルの持ち主の Google アカウントでログイン）
2. 上部のプロジェクト選択 → **新しいプロジェクト** → 名前（例: `shorts-scheduler`）で作成
3. 左メニュー **API とサービス → ライブラリ** で、次の2つを検索して **有効にする**
   - **YouTube Data API v3**
   - **Google Drive API**
4. **API とサービス → OAuth 同意画面**（「Google Auth Platform」と表示される場合もあります）
   - ユーザーの種類: **外部**
   - アプリ名・サポートメール・連絡先メールを入力して保存
   - **対象（テストユーザー）** に自分の Gmail アドレスを追加
5. 左上のプロジェクト名の横などに表示される **プロジェクト番号**（数字）を控える

> 補足: テストモードのままだと、7日ほどで認証が切れます。そのときは次に実行したときにもう一度「許可」を押すだけで使えます（月1回の運用なら毎回許可を押す形になります）。

### B. スプレッドシートとスクリプトを用意する

1. Google ドライブで新しいスプレッドシートを作る（名前は自由。例: `YouTube予約投稿`）
2. メニュー **拡張機能 → Apps Script** を開く
3. 左の歯車 **プロジェクトの設定** で
   - **「appsscript.json」マニフェスト ファイルをエディタで表示する** にチェック
   - 下の **Google Cloud Platform（GCP）プロジェクト → プロジェクトを変更** に、A-5 のプロジェクト番号を入れて設定
4. エディタに戻り、
   - `Code.gs` の中身を全部消して、このフォルダの **`Code.gs`** を貼り付け
   - `appsscript.json` の中身を、このフォルダの **`appsscript.json`** に置き換え
   - 保存（Ctrl+S / ⌘+S）
5. スプレッドシートを再読み込みすると、メニューに **YouTube予約投稿** が出ます
6. **① 初期設定（シート作成）** を実行
   - 初回は「承認が必要です」と出ます → アカウントを選択 → 「このアプリは Google で確認されていません」と出たら **詳細 → （プロジェクト名）に移動** → **許可**
   - **YouTube チャンネルがブランドアカウントの場合**、アカウント選択画面でそのチャンネルを選んでください
7. 「設定」シートの **動画フォルダ** に、動画を置くドライブのフォルダURLを貼り付ける
   - （任意）**投稿済みフォルダ** を入れると、予約が終わった動画をそこへ移動するので、次の月に重複しません

スプレッドシートのタイムゾーンが **(GMT+09:00) 東京** になっていることも確認してください（ファイル → 設定）。

### C. YouTube API の審査を申請する（無料・必須）

2020年7月以降に作った API プロジェクトは、審査に通るまで、アップロードした動画がすべて「非公開」に固定されます。

1. まず B が終わった状態で、動画を **1本だけ** 予約アップロードして、動作を確認する（この時点では非公開のままで正常です）
2. 申請フォーム（YouTube API Services - Audit and Quota Extension Form）から申請する
   <https://support.google.com/youtube/contact/yt_api_form>
   - 用途は「自分のチャンネルに、自分で撮った動画を予約アップロードするための社内（個人）用ツール。利用者は自分のみ」と正直に書く
   - 使うAPI: `videos.insert`（`youtube.upload` スコープのみ）
   - 画面の説明やスクリーンショットを求められたら、スプレッドシートとメニューの画面を添付する
3. 審査が通ったら、以降のアップロードは予約日時に自動で公開されます

> 審査結果は Google の判断なので、通ることは保証できません。審査待ちの間（または通らなかった場合）は、YouTube Studio の予約機能で手動予約してください。ドライブとスプレッドシートの一覧は、そのまま手動予約の下書きとして使えます。

## シートの列

| 列 | 内容 |
|---|---|
| 投稿する | チェックした行だけ YouTube にアップロード |
| ファイル名 | ドライブ上の動画ファイル名（取り込み時に自動入力） |
| ファイルID | 自動入力（非表示列。消さないでください） |
| タイトル | 100文字以内。取り込み時はファイル名が入るので書き換えてください |
| 説明 | 5000文字以内。「設定」の「説明の末尾に付ける文」が自動で付け足されます |
| タグ | カンマ（, または 、）区切り |
| 公開日 | ③で自動入力、または手入力 |
| 公開時刻 | 空欄なら「設定」の公開時刻（初期値 18:00） |
| ステータス | 予約済み／エラー内容 |
| 動画URL | 予約後に自動入力 |

`<` と `>` はタイトル・説明に使えません（YouTube の制限）。

## 無料枠について

- YouTube Data API: 1日あたり100本までアップロードできます（月10〜20本なら十分です）
- Apps Script: 1回の実行は6分まで（超えそうなときは自動で分割して続行します）
- 料金が発生する設定は一切ありません。請求先アカウント（クレジットカード）の登録も不要です

## TikTok について

TikTok の API は、個人用ツールだと審査が通りにくいです。審査前は投稿がすべて非公開になるうえ、予約投稿の機能もありません。そのため TikTok は、**TikTok Studio（Web版）の予約投稿（最大10日先まで）** を使う運用がおすすめです。
このシートに TikTok 用のチェック列を自分で足して、投稿の管理表として使うこともできます。
